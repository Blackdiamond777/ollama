# Контур — сайт делового нетворкинга

Статический сайт клуба деловых знакомств: каталог участников, двусторонний подбор
по встречным запросам, расписание встреч и заявка на вступление.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка страницы |
| `styles.css` | токены темы (светлая/тёмная) и компоненты |
| `app.js` | данные, подбор, фильтры, форма заявки |
| `build-artifact.py` | сборка однофайловой версии для публикации |

## Как устроен подбор

У каждого участника есть два набора тем из общей таксономии (`TAGS` в `app.js`):
`offers` — чем он полезен, `needs` — что ищет. Посетитель отмечает то же самое
за себя, и совпадение считается в обе стороны:

```
score = |мои needs ∩ его offers| + |мои offers ∩ его needs|
```

Совпавшие темы подсвечиваются прямо в карточке, каталог сортируется по score.

## Запуск

Сборки не требуется — откройте `index.html` в браузере или поднимите статику:

```sh
python3 -m http.server 8000 --directory business-networking
# http://localhost:8000
```

Однофайловая версия (весь CSS и JS внутри одного HTML):

```sh
python3 business-networking/build-artifact.py dist.html
```

## Данные и хранение

Участники и встречи — демонстрационные, лежат в `app.js`. Заявка, выбранные темы,
записи на встречи и тема оформления сохраняются в `localStorage` браузера
посетителя: бэкенда нет, наружу ничего не уходит. Чтобы подключить реальный приём
заявок, замените `handleSubmit` в `app.js` на отправку на ваш эндпоинт.

## Доступность и темы

Светлая и тёмная темы описаны токенами на `:root`, переключатель в шапке
перекрывает системную настройку. Карточки участников доступны с клавиатуры
(Enter/Пробел), анимации отключаются при `prefers-reduced-motion`.
